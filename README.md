# Парсер товарного каталога с SQLite

Асинхронный скрипт на Python для сбора карточек товаров. Текстовые данные сохраняет в SQLite, изображения скачивает в папку `pictures/`.

Исходник настроен под каталог FashionReps. Для другого магазина нужно изменить адреса, селекторы и правила обработки полей.

## Что сохраняется

Название, описание, цена, категория, артикул, ссылка, цвет, размер и пути к изображениям. База `database.db` и таблица `items` создаются при запуске. Для уже встречавшихся товаров предусмотрено обновление категории.

## Запуск

Установите зависимости в отдельное виртуальное окружение:

```bash
python -m pip install aiohttp aiosqlite beautifulsoup4 tqdm
```

Создайте папку `pictures` рядом с `main.py`, проверьте список категорий и количество страниц в `main()`, затем выполните:

```bash
python main.py
```

## Перед использованием

- Скрипт рассчитан на определённую разметку WooCommerce.
- В исходнике из каждой цены вычитается 25 долларов. Это правило конкретной выгрузки; проверьте его перед использованием.
- Поля `DescDetail` и `DescDetailImg` сейчас заполняются в обратном порядке относительно их названий.
- Общее состояние обработки описания используется несколькими асинхронными задачами и требует проверки перед большой выгрузкой.

Зависимости в репозитории не зафиксированы по версиям. Сначала проверьте результат на небольшой категории.
